La comunicación serial UART entre dos Arduino Uno separados 20 metros usando únicamente cable AWG24 es técnicamente posible, pero no es completamente confiable. A esa distancia pueden aparecer problemas como ruido eléctrico, pérdida de señal, diferencias de tierra entre edificios y errores de sincronización, especialmente si se usan velocidades altas de transmisión. UART fue diseñada principalmente para distancias cortas, por lo que una conexión directa entre edificios puede volverse inestable.

Una posible solución es utilizar módulos RS-485, por ejemplo MAX485, conectados a cada Arduino. RS-485 convierte la comunicación UART en una transmisión diferencial, lo que permite enviar datos de forma mucho más estable a largas distancias y con mayor inmunidad al ruido eléctrico. Esta tecnología está diseñada específicamente para comunicación industrial y puede funcionar correctamente incluso a cientos de metros usando el mismo cable AWG24.
